# 首页与家庭导航

按 2026-09-14 用户要求调整原设计：家庭管理成为常驻一级入口，原有首页事项布局和家庭权限规则保留。

## 视觉与结构

沿用品牌紫 `#5860b5`、淡紫 `#ececf8`、画布 `#f4f5fa`、纸白 `#ffffff`、正文 `#292735`、辅助文字 `#72717f`。标题使用既有楷体 display 字体，正文使用苹方等系统字体。昵称使用 22px 半粗正文，家庭名 16px，辅助信息 12px。

签名元素是左下角收紧的昵称头像，与房屋形状的家庭图标呼应。家庭列表保持安静的白色卡片，不增加装饰统计或额外动画；整张卡片可点击。

```text
家庭

[首字头像] 当前昵称
           照应彼此的小家

我的家庭                         2 个家庭
[小屋] 家庭名称                         ›
       我管理的家庭 · 拥有人 …
[小屋] 家庭名称                         ›
       我加入的家庭 · 拥有人 …

家庭管理
[创建另一个家庭] [加入家庭]
[家人进度                              ›]
[回收站                                ›]

            首页          家庭
```

身份接口提供默认昵称；用户可主动选择微信头像、填写昵称并保存在本机，未设置头像时显示昵称首字。具体交互见下方「头像昵称设置」。

## 交互

- 微信原生图标加文字 tabBar 固定展示「首页 / 家庭」，选择态由平台管理；首页「记一件事」保持在页面底部、导航上方。
- 首页原来的右上角家人图标移除；家庭页提供家人进度入口。
- 点击家庭卡片进入同页家庭详情；顶部返回箭头返回列表。邀请、成员管理、退出和转交沿用已有流程。
- 加入成功使用 `switchTab` 返回家庭；目标 ID 仅在进程中一次性传递，重新读取家庭列表检查权限。不向 tab URL 添加查询参数。
- 空家庭状态仍可创建或加入；加载失败提供重试。隐藏页面时失效旧读取，每次显示重新加载。
- 原生导航在页面弹层下方，真机需验收安全区、软键盘、切换 tab 后草稿恢复和未决操作确认。

## 样式走查优化

2026-09-14 按用户要求采用 emil-design-eng 走查首页、家庭页、家人进度与通用弹层：

- 提示、错误和页尾文案独立成行，空错误不额外占用间距；统计行至少 44px，避免按钮热区挤压进度条。
- 首页筛选名称过长时省略，事项和家庭名称允许换行；进度卡片头像跟随文本排布，避免绝对定位遮挡标题。
- 家庭成员操作使用自适应并排按钮，去掉卡片中全宽按钮规则带来的额外边距，退出按钮与上方操作保持间隔。
- 首页底部按钮只保留 12px 内边距，安全区由原生 tabBar 承担；弹层内容区扣除头部和安全区高度后滚动。
- 主操作、次操作、关闭按钮及家庭入口提供 120ms 轻微按压反馈；减少动态效果偏好下取消缩放与骨架动画。

本轮 `npm run typecheck` 与 `git diff --check` 通过；微信开发者工具重新编译无错误，已查看首页、家庭列表、家人进度及提醒弹层。这些验证不代表 iOS/Android 真机、软键盘和长名称极限输入已验收。

## 家庭详情精简

家庭详情隐藏顶部个人昵称和头像，个人信息仅在家庭列表展示。真实成员与无账号成员的修改称呼入口使用成员信息右侧的编辑图标，保留 44 × 44px 热区及包含成员名称的无障碍标签；显示权限和原编辑弹层不变。删除成员操作使用独立文字按钮。

家庭详情导航栏固定显示返回箭头及「家庭详情」标题，滚动时仍可返回家庭列表，沿用 allFamilies 切换逻辑。

## 底部导航图标

首页使用清单图标，家庭使用房屋与家人图标。默认灰紫描边，选中时使用品牌紫和淡紫圆角底，使状态同时具有颜色与轮廓区别。沿用原生 tabBar 的图文间距、触控区域和安全区，不增加切换动画。

图标为本地 81 × 81 透明 PNG，由 `design/assets/tabbar/generate.py` 生成（手动执行需 Python Pillow），不进入应用运行时依赖。

家庭管理中的回收站入口使用品牌紫垃圾桶图标（`trash-brand.svg`），与重试、重复图标区分。

### 头像昵称设置

家庭列表顶部原头像与昵称区域可点击，沿用现有底部弹层：居中头像选择按钮、昵称输入框与保存按钮。微信原生头像选择和昵称推荐由用户主动触发；头像裁切保持原圆角。关闭放弃草稿，保存后更新顶部展示。当前资料保存在本机，家庭称呼保持独立。

占位头像与已设置头像统一为 64 × 64 px；头像按钮显式固定宽度，避免被全局按钮自适应宽度规则覆盖，首字保持水平及垂直居中。


## 家庭子页面间距与骨架走查

覆盖家庭详情及管理弹层、邀请管理与加入、家人进度、回收站，延续现有颜色、字体和圆角。

- 卡片内边距统一 16px，卡片间距 12px，段落间距 8px，分区间距 24px；筛选控件与列表间距 16px。
- 弹层标题与内容间距 16px，首个字段不再叠加顶部外边距；字段间距 20px、标签与输入框间距 8px、主操作上方 20px。
- 并排操作使用 8px 间距且允许换行，消除全宽按钮样式造成的额外外边距；邀请口令独立成块并允许长内容换行。
- 进度页单家庭时隐藏重复的切换按钮，成员信息与进度环分列，说明与列表间距 24px。底部滚动区域包含安全区，原生家庭 tab 单独保持 24px 留白。
- 加载骨架按家庭列表、详情、邀请表单、成员进度和回收站布局呈现；交接预览使用文字行骨架。首次进度加载补齐封面占位，家庭详情加载保留返回入口并避免闪出个人资料。
- 骨架提供加载说明，不包含可点击控件；减少动态效果时关闭淡入淡出动画。

本地 `npm run check` 通过（35 个测试文件、428 项测试）；WXML 经微信开发者工具实际编译。模拟器检查不替代 iOS/Android 真机验收。

### 家庭详情底部操作区补充

成员卡片与操作区保持 16px 留白；添加成员和邀请横排，转交拥有权独占一行，组内及退出按钮上方统一 12px。家庭管理区上方 28px，标题到按钮 12px，按钮到工具卡片 12px，使用独立容器消除通用外边距叠加。

### 删除家庭成员

家庭拥有人可在真实成员和无账号成员卡片上点击「删除成员」。真实成员展示交接预览，确认后移除成员关系；不能删除当前拥有人，退出前须转交。无账号成员弹窗说明删除后从列表隐藏、不能用于新事项，历史记录和未结束事项保留并由拥有人管理；确认按钮为「删除成员」。底层沿用停用能力，已停用成员也不再显示在此列表。取消不写入，确认期间切换家庭或离开页面使旧确认失效，网络结果不明时使用原请求重试。

删除入口本地验证：`npm run check` 通过（35 个测试文件、433 项测试），包含删除确认、取消、权限限制、跨家庭旧确认失效及已删除成员隐藏。尚未进行本次删除操作的开发者工具、真实云环境或真机验收。

## 家庭详情的成员进度与管理区

按用户补充要求：家庭详情不展示「创建另一个家庭」「加入家庭」和独立「家人进度」入口。创建／加入操作仍在家庭列表页。真实成员与无账号成员卡片直接显示当日已完成、待完成、跳过及完成分母；口径仅包含共享给当前用户的事项，无共享数据不能推断为没有完成。加载或失败在进度区域提示，可单独重试。

家庭详情底部管理区保留回收站；进入时固定当前家庭，隐藏跨家庭筛选，不可访问时显示错误，不回退为全部家庭。全局入口的回收站保留原筛选。

成员进度按最新要求使用圆环，中心显示「已完成数 / 总量」，圆环按同一完成比例填充；无共享安排显示空环 `0/0`，加载及失败仍单独提示。真实成员和无账号成员复用同一圆环组件。

圆环放在成员信息行右侧、编辑图标左边；无编辑权限时仍在信息行右侧显示。
