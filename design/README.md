# 家庭待办界面设计

本目录是当前正式设计基线，已按用户确认替换旧版设计稿。覆盖 7 个原生页面、家庭详情内部视图及主要弹层。原型采用虚构数据，用于查看页面与交互；设计切换不代表原生小程序已完成同步。

## 入口

- [完整交互原型](index.html)
- [页面与交互规范](page-redesign.md)
- [样式与视觉 tokens](styles.css)
- [浏览器验证记录与限制](VALIDATION.md)

在仓库根目录运行：

```sh
python3 -m http.server 4397 --bind 127.0.0.1 --directory design
```

打开 [设计预览](http://127.0.0.1:4397/)。资源均在本地，无新增 npm 依赖。

## 当前设计约定

- 所有事项归属家庭；没有家庭时先创建或加入。
- 可操作事项用白底与完成圆框；只读事项用浅灰底和眼睛图形，独立分区，不逐条显示权限标签。
- 家庭卡片采用两行布局：名称与进入箭头，人数与本人角色；具体成员在详情中查看。
- 进入箭头使用 20 px 图标区域；下拉箭头距右边缘 14 px。
- 当前样式主色为 `#5059ad`，页面底色为 `#f5f6fa`，以样式文件中的 tokens 为准。

旧主稿、完整流程稿、演示流程模型及其测试、家庭导航旧规范已删除。后续实现统一使用本目录当前原型与规范，历史版本可通过 Git 查看。
