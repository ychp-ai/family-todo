# 家庭待办界面设计稿

本目录是独立的浏览器交互设计稿，以 [首版需求](../docs/REQUIREMENTS.md) 为依据。它用于评审页面、视觉和交互，不代表原生小程序业务已经实现。演示数据均为虚构，刷新即重置。

## 预览

在仓库根目录执行：

```bash
python3 -m http.server 4387 --bind 127.0.0.1 --directory design
```

打开 [主设计稿](http://127.0.0.1:4387) 或 [完整流程](http://127.0.0.1:4387/flows.html)。使用本地 HTTP 服务预览，避免直接打开文件时浏览器限制 JavaScript 模块。无新增 npm 依赖，无外部字体或资源请求。

## 视觉方向

主题是「把关心，放进每一天」：以家庭日常为中心，让执行对象、家庭来源、代记人比数字统计更显眼。首页采用分组事项清单；详情展示一次完成及真实记录人；家人页以一组高低错落、相互靠近的人物标记体现家庭关系。数字只表达当前有权查看的记录，不作排行榜。

沿用项目蓝紫色主色。轻微变化的灰白、淡紫和草木绿划分页面、提醒和完成反馈，不以颜色作为唯一状态标识。

| Token | 色值 | 用途 |
| --- | --- | --- |
| brand | `#5860B5` | 主要操作、选择状态、进度 |
| canvas | `#F4F5FA` | 页面底色 |
| paper | `#FFFFFF` | 事项与信息卡片 |
| ink | `#292735` | 主要文字 |
| lavender | `#ECECF8` | 家庭入口与轻提示 |
| green-light | `#E8F0EB` | 已完成背景，配合文字和勾选 |

标题使用系统楷体栈 `Kaiti SC / STKaiti / KaiTi`，只用于少量问候与品牌标题；正文使用 `PingFang SC / Hiragino Sans GB / Microsoft YaHei`；数字使用 `Avenir Next` 并回退到系统字体。具体效果随设备字体而变化。正式小程序接入时需要根据真机字体情况验收。

## 页面与交互

- **今日待办**：全部家庭聚合，按个人、小家、爸妈家筛选；今天、明天、未安排和其他日期；“今天”“明天”标签仅展示文字，不附加具体日期；按我来做、帮家人、关心一下分组；显示或隐藏已完成；积压记录折叠。
- **事项详情**：家庭与执行对象、每次完成状态、真实记录人、可见人、可代记家人和历史记录；有权限时完成、撤销和修改名称；只读事项显示权限说明。
- **家人进度**：按家庭查看有权访问的安排；展示无账号成员；查看家庭成员、添加无账号成员。邀请入口展示界面说明，不发送消息。
- **快速新增弹层**：只填标题也能保存；可连续新增；默认个人且仅自己可见，小程序内提醒自己默认开启，可手动关闭；未设置具体时刻时不产生到时提示。展开后选择家庭、执行对象、每日重复、时刻和可见人。虚拟人明确归属家庭拥有人，其他家人不默认选中。
- **到时提醒弹层**：始终跨家庭汇总；收起只影响提示，不完成事项。明确说明小程序关闭后不会发送微信通知。
- **多选共享弹层**：按家庭分组增加可见人，保留原名单；个人事项先明确归属；不同时授予代记或提醒权限。
- **异常状态**：页面底部可切换加载中、空列表、失败、部分加载失败；部分失败不汇总成完整统计，支持重试。

三个画板的完成状态与数据联动。桌面并排对照，中等宽度两列，手机纵向排列。画板内部独立滚动，主要操作固定在底部；首页右上角家人入口可跳到家人进度画板。此处为原始提案；最新「首页 / 家庭」底部导航与家庭入口以 [家庭导航设计](family-navigation.md) 为准。

## 验证与边界

本地浏览器已检查：完成/撤销与汇总联动；家庭筛选保留跨家庭提醒；收起提示不完成事项；只读权限；明日新增、连续新增及默认私密；无账号成员的归属说明；多家庭批量追加且不授予代记；家人筛选；失败重试和部分失败统计。脚本语法检查通过，交互检查期间没有页面控制台错误。

已检查 1280 px 桌面布局，以及 390 px、320 px 手机宽度；320 px 下页面和三个画板均无横向溢出。添加无账号成员后，成员列表和数量同步更新。此处是浏览器模拟检查，不是微信真机验收。

提醒默认开启变更已通过浏览器交互检查：新增弹层默认勾选；只填标题保存后显示「已开启 · 待设置时刻」且不增加到时提示；填写已到时的具体时刻后增加提示；手动关闭后保存不增加提示，详情显示「未开启」。

完整流程页补充每周多时刻编辑、权限取消确认、家庭创建/称呼/虚拟人管理、邀请接受/撤销、退出与转交、补记/跳过/撤销、暂停/停止/恢复以及版本冲突与批量失败重试。编辑草稿、家庭、记录分别使用独立样例；记录与回收联动，家庭与邀请联动。时间固定为 2026-09-11 18:30，交接计数为演示值。

最新确认的真实家人免接受安排、周期换人保留历史、已完成事项编辑限制、本人关闭提醒优先和可转发多人邀请，已写入需求及业务开发设计；现有浏览器样稿未完整模拟这些边界，不能据样稿的简化行为覆盖文档规则。

设计稿不包含持久化、真实登录、云接口、真实邀请和完整周期引擎。字段、接口、状态和验收映射见 [业务开发设计](../docs/business/DELIVERY.md)。没有修改原生小程序代码，没有云部署或真机验证。本次不涉及基础架构或契约变更，未运行完整 `npm run check`。

流程模型的行为检查：`node --test design/flow-model.test.mjs`。此命令仅验证演示规则，不替代正式领域/云端测试。
