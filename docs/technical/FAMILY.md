# 家庭协作实现

本阶段接入家庭、邀请、真实/无账号成员、退出与拥有权转交、一次性事项协作和多家庭查询。服务端已部署，原生页面已接入；实际验证边界以 [发布记录](CLOUD_DEPLOYMENT.md) 为准。现已在同一路由实现周期、按人进度与批量追加；算法和数据边界见 [日程实现](SCHEDULING.md)，原生接入与部署状态见 [当前范围](../SCOPE.md)。订阅消息尚未实现。

## 入口与权限

单一 api 注册健康、身份、19 个家庭 action 和 22 个事项/次数/提醒/进度 action，共43个。请求、响应与 unknown 校验定义在 contracts 的 family.ts/personal.ts。application 的 FamilyService 编排家庭生命周期，CollaborativeTaskService 将既有个人事项与家庭事项统一路由，CollaborativeLists 合并个人及最多10个家庭；OccurrenceLists 负责周期与一次性次数的有界投影，ProgressService 在完整扫描后汇总可见执行人进度，BatchViewers 按单项事务追加可见人。

家庭拥有人与普通成员只能看到自己有权查看的事项。普通私密事项不会因为家庭角色而向拥有人公开。普通事项的归属人和有效创建管理者可管理；真实执行人必要可见、可记录，不因此自动具有编辑或提醒权限。虚拟事项的归属人随当前家庭拥有人解析，创建者保留管理职责。退出通过历史 membership 的 successor 链继承管理责任，重新加入创建新 membership；称呼不授予权限。

执行人、必要查看人、显式查看人、可代记人、提醒接收人分别计算。参与者 DTO 的 isCreatorManager 由服务端解析创建管理职责的承接链后返回，客户端更换执行对象时据此保留创建管理者，并重算新执行人及虚拟事项当前家庭拥有人的必要查看权，不能按称呼或旧 requiredViewer 标志猜测。为兼容已持久化的旧写回执，契约允许该字段缺省；实时读取始终返回，客户端缺失时须刷新后才能更换执行对象。管理者可见完整权限矩阵，普通查看者无法获知他人的提醒设置。提醒偏好按事项/用户存储，自己关闭后 selfDisabled 保留；撤权、重新加入、恢复不会重置本人选择。已读与收起按单次/用户保存，不改变完成状态。

## 写入与重试

业务身份只来自本次微信调用上下文。事务内校验当前成员槽、家庭版本、事项版本、权限、容量，同时写入业务实体、审计及 actor/requestId 回执。家庭写更新共同的 family.version，权限变化同时更新 authEpoch。个人与家庭共用幂等键，个人事项归属家庭后仍可确认原新增请求。仅归属家庭且执行人和时间不变时，保留原单次身份、完成历史与本人已读/收起回执；实际改期或换人才产生新单次。虚拟事项改为真实执行人后归属回有效创建管理者，若原操作者失权，返回可重放的最小更新确认，客户端清理详情。

邀请有效期7天，16随机字节编码为22字符口令；邀请实体只存口令散列。只有原创建人仍为拥有人且邀请有效，才能解密重放创建回执。服务端使用独立邀请密钥环，保留历史 keyId 的解密能力；密钥不得进入客户端、日志或版本库。服务端 `FAMILY_TODO_INVITATION_KEYRING` 配置为 JSON：`{ activeKeyId, keys: { [keyId]: secret }, legacyV1Secret? }`，每个密钥至少32字节；生产环境缺失或格式非法时拒绝启用家庭存储。CloudBase CLI 会自动解析 JSON 字符串，cloudbaserc.json 中应使用 `base64url:` 前缀加 JSON 的无填充 base64url 编码；云端也兼容直接配置 JSON。此编码只解决传输格式，不是加密，仍按密钥管理。轮换先加入新 keyId 并更新 activeKeyId，保留旧 keys 供有效回执解密。legacyV1Secret 仅用于迁移旧 v1 加密回执，本环境首次启用无需设置。

退出/转交预览绑定操作者、完整参数、家庭版本和5分钟有效期。扫描完整前只返回续页，不返回部分计数或确认口令。提交时再次核验，版本变化必须重新预览。退出成功后原操作者可以按原 requestId 确认最小成功结果，不获得家庭详情；转交也仅重放最小确认。

事务最多80次文档操作，家庭操作共享8秒预算，为10秒云函数回包留出余量。每次事务启动或明确冲突重试要求至少2秒，最多重试2次。长链不能截断来换取成功；若不能完整解析则安全失败。预览与查询在可保存的分页边界提前停止，为版本复查及检查点保存保留时间。

## 查询与数据兼容

所有家庭事项先按家庭索引扫描，再以当前归属和权限过滤，因此可以找出完全由退出承接得到的事项。没有只按原 ownerUserId 查询而漏掉承接项的问题。旧个人读取器拒绝家庭扩展文档，个人数据无需批量改写。

各范围产生有序记录流，取得所有未结束范围的下一个候选后才输出全局下一项。每次最多200候选读取，可返回空但未结束的续页。检查点绑定用户、筛选、用户家庭版本、各家庭版本和首次查询时间，15分钟有效；跨上海午夜的续页沿用首次筛选日期。完成全部扫描且无失败范围才返回 summary。家庭范围暂时失败时聚合明确标注，回收站整体返回可重试失败，不能显示为完整空列表。

存储键、索引、管理员权限和迁移见 [家庭数据](../../database/family.md)。没有定时清理或外部服务调用作为正确性的前提，未新增云函数、业务 tabBar 或付费套餐。

## 验证边界

本地事务模拟测试覆盖容量、成员继承链、权限隔离、邀请幂等与撤销、退出/转交、提醒本人关闭优先、回滚、分页与游标失效。真实云端流程和页面验收另记发布记录；模拟多身份不等于两个真实微信账号或真机验证。

小程序未决写在进程内保留原 requestId/参数；跨进程恢复仍未实现。开发者工具编译或云函数更新不代表上传体验版或发布小程序。
