# 小程序实现方案

适用原生 WXML/WXSS + TypeScript。视觉沿用 `miniprogram/styles/tokens.wxss` 及浏览器设计稿，路由和产品交互见 [页面流程](../business/INTERACTIONS.md)。浏览器模拟状态和固定时间不进入正式实现。

## 服务与状态职责

| 模块 | 计划职责 |
| --- | --- |
| `services/identity-api.ts`、`family-api.ts`、`task-api.ts`等 | 构造强类型请求，引用生成contracts运行时校验，返回稳定DTO |
| `services/request-manager.ts` | requestId生命周期、超时结果未知、未决写请求及继续批量 |
| `services/session.ts` | identity初始化Promise去重、当前用户、家庭名单revision、失权清理 |
| `services/reminder-refresh.ts` | 可见页面共享一次前台刷新，onHide停轮询；仅一个实例计时器 |
| `pages/*/index.ts` | 日期/家庭筛选、draft、分页、selection和局部UI状态 |
| `components/` | task-card、member-selector、permission-list、time-slots、状态与确认弹层，按复用证据提取 |

不引入大型状态库。App仅保存云初始化与会话协调器；数据页用明确状态 `loading/empty/error/ready/partial`，写状态另设 `idle/submitting/unknown/conflict`。页面setData只更新可展示的有限数组，不放仓储对象、Map或整个历史数据集。

## 初始化与失权

onLaunch只初始化云可用状态；首页onShow调用session.ensure，成功后并行获取当前日期事项与跨家庭提醒。无家庭仍显示个人首页，初始化失败不是“无家庭”。邀请路径先暂存口令，身份就绪后预览，主动确认才加入；口令不写日志/持久缓存，离开邀请流程即清除。

每次读取后记录scope版本。页面返回前台重新校验会话与可见数据；成员退出或权限失效时清理相关scope卡片、统计、提醒、选中项及敏感草稿展示，关闭写入口。服务器不能撤回用户已看过的信息，客户端也不把离线缓存当当前授权。

## 请求上下文与乱序响应

列表维护 `queryGeneration`。改变日期/家庭/状态或刷新第一页时递增；调用捕获generation，响应只在仍匹配时应用。编辑捕获taskId/familyId，不从页面最新筛选读取提交目标。onUnload标记disposed，迟到回调不setData；SDK调用不能取消时忽略过期结果。

mutation成功后局部更新对应ref，再使相关日期/家庭摘要和提醒失效并刷新；移出当前筛选的数据不强行插回旧列表。多身份命中按occurrenceId去重；历史行展示OccurrenceDTO的subject，不用Task最新subject。分页追加检查cursor来自同generation，CURSOR_EXPIRED保留筛选回到第一页。

## 写请求与重试

1. 用户提交前生成UUID，持有完整规范化payload；禁用重复提交，按钮显示保存中。
2. 失败分为已确认业务拒绝和结果未知。10秒超时/网络丢失显示“暂未确认是否保存成功”，不得自动创建第二个requestId。
3. 当前用户明确重试时，发送相同requestId/action/payload。错误需要修改草稿时，先确认原请求未提交或取得其结果；不能在未知结果上直接换ID重复新增。
4. 已确认版本冲突时保留本地草稿，加载最新值逐字段显示差异，由用户选择后生成新请求；权限名单不能机械取并集，本人关闭提醒不可被覆盖。
5. 单项成功清除未决记录；批量complete=false继续同一命令，complete=true才允许用新ID重试明确失败项。

为跨重进保存未知结果，request-manager只持久化当前账号最近未决写请求，最多20条，按actor隔离、序列化总量≤256 KiB；不缓存邀请token、身份凭据或历史列表。超过容量在发送新写之前提示先处理未决请求，不能发送后悄悄丢弃。启动只展示“有待确认操作”，重新鉴权后由用户继续，不自动重放离线队列。退出相关家庭时移除其正文及一般写草稿；尚未确认的退出/转交命令只保留原 requestId、action 和完整的无正文 payload（包括原 previewToken/expectedFamilyVersion），以保持重试 hash 一致。该令牌绑定原用户与动作，不含事项内容，不授予其他读取能力；服务端命中回执后不重新要求预览有效，确认成功即删除本地未决记录。其他失权命令停止重试并删除本地 payload。对必须携带敏感口令重试的邀请创建/接受，不写口令到本地；重进后读取当前家庭/邀请状态或让用户重新打开邀请，不能靠日志恢复口令。

UUID使用平台密码学随机能力并在最小支持基础库上验证；不能用Date.now/Math.random当可靠请求唯一来源。不支持所需基础能力时给出升级微信提示，不能静默降低唯一性保证。基础库支持验证属于平台接入检查。

## 长列表与批量体验

列表每页20，上限50；查询empty但complete=false时显示“继续加载”，不能显示空态。主动可见期间自动继续最多3页以取得首屏；仍未结束提供按钮继续，避免无限自动请求。完整总数就绪前显示“统计中/仅已加载”，部分失败显示受影响家庭与重试。

批量每项保留taskId、familyId、expectedVersion和组内新增名单。进度显示成功、失败、待继续三类；退出页面前提示尚有未处理项目，重新进入可继续已授权命令。成功项不再次选择；失败项可改权限或刷新版本后重试；未决项不能当失败重新提交新ID。

长列表按分页加载，setData只保留必要展示字段；首版先采用分组分页，性能实测再决定是否做虚拟列表，不提前引入跨端组件。

## 前台提醒

session级refresh协调器在进入/返回前台立即刷新（2秒去重），可见期间30秒一次；onHide停止。失败退避5/15/30秒最多3次，保留手动重试。网络刷新时钟依据服务端asOf，客户端只展示倒计时或触发重新读取，不能自行决定记录已到时。

首页家庭筛选不传给reminder.list；读取使用所有scope，提醒读取和列表请求不互相替换。读过/收起调用独立接口；完成/跳过/删除后重新刷新，不能靠本地把提示收起代替业务写入。无时刻仍显示提醒设置开启但不出现到时提示。

## 草稿、可访问性与真机验收

完整编辑本地draft独立于远端Task，提交成功后才替换基线版本。家庭事项从 ResolvedSubject 映射为实际 member/virtual ID，不能用 self 替换原执行人；既有失效对象保留显示且不能重新选用。普通返回可确认保留/放弃，保留采用同账号本地草稿并在重新进入时先鉴权；失权不继续展示内容。日期/时刻控件遵循本地日历输入；输入错误紧邻字段，保存失败保留输入。

触控热区≥44 CSS px，不仅靠颜色区分状态；微信小程序实现选择器、弹层焦点、安全区及键盘避让。浏览器WXML替代稿不能证明微信组件行为，必须使用至少两个真实账号测试权限、邀请、交接和协作；320/390宽度、老人常用字体大小、前后台切换与断网重进分别验收。

## 客户端测试重点

- 旧家庭请求后到不会覆盖新筛选；页面卸载后回调不更新。
- 写成功后丢响应，重试仍同ID，重进从未决记录确认，不重复新增。
- 完成与改期并发，冲突草稿保留；成员退出后旧页面不能继续显示或提交。
- 本人关闭提醒后管理者矩阵锁定；并发时服务端拒绝，界面不显示保存成功。
- 空页continuation、部分scope失败、批量pending与failed分开，完整摘要不提前展示。
- health与未配置环境仍可加载；生成的contracts不含Node/SDK运行时依赖。
