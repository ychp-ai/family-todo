2026-10-12 增加本地信息页面；本轮不新增服务端 action、数据库字段或授权状态。

## 入口与内容

- 家庭列表底部「关于小程序」，在 loading / empty / error / ready 状态均可进入，不依赖家庭数据或身份初始化成功。家庭详情内部视图返回家庭列表后可访问。
- 关于页展示名称「家庭待办提醒」、简介、当前能力、微信实际版本及运营信息。运营者为用户确认的「应程鹏」，隐私联系邮箱为 `ychp0117@sina.com`。
- 优先显示微信返回的版本号，如「版本 1.2.3 · 正式版」。微信未返回版本号时显示「本地版本 1.0.5 · 开发版/体验版」；接口不可用时显示「本地版本 1.0.5」。本地版本维护于 `product-info.ts`，当前与项目版本 `1.0.5` 一致，发版时同步更新；明确标记本地来源，不冒充微信发布版本。
- 用户协议、隐私说明通过同一个正文页面按白名单参数展示；未知参数显示未找到及返回关于入口。使用原生导航栏和页面滚动，文字可选择。
- 基本信息统一维护于 `miniprogram/config/product-info.ts`，正文维护于 `miniprogram/config/legal-documents.ts`，样式复用现有 tokens。设计补充见 [页面规范](../../design/page-redesign.md)。

## 说明依据与实际边界

内容依据当前业务、身份映射、本机资料、草稿/未决操作、家庭交接及回收站实现撰写：头像昵称仅保存在本机；家庭/事项/历史及回执在云端；仅小程序内提醒；当前没有自助注销、彻底删除、导出与家庭解散。页面不承诺未实现的删除期限或通知能力，不将阅读页面视为已同意，也不新增强制勾选或同意弹窗。

查阅参考：[《个人信息保护法》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_f374e8245320413181742e6d1baf4366.html)中的告知与个人权益要求；[腾讯云的小程序隐私保护指引适配说明](https://cloud.tencent.com/document/product/1301/97930)。这些基础页面不能单独代表已经完成平台隐私配置或全部合规工作。

发布前仍需核实并落实：

1. 微信公众平台中的运营主体、隐私指引、头像/昵称等实际使用接口声明及授权流程，与当前功能一致；本次未修改平台设置。
2. 云环境实际存储地域、日志保存期和业务数据保留/删除策略；现有业务数据没有自动到期清理，不虚构期限或地域。
3. 隐私邮箱可用及人工查阅、更正、复制、删除、撤回同意等处理流程。现有小程序没有自助注销、彻底删除或导出接口。
4. 如果面向不满十四周岁的儿童或处理健康等敏感信息，另行确认专门规则、监护人同意及必要授权；本次基础文案不等于已经实现这些机制。
