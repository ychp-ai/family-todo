# 原生页面改版落地

2026-09-15，按 `design/index.html`、`design/page-redesign.md` 和 `design/styles.css` 当前设计基线更新全部 7 个原生页面及家庭内部详情、主要弹层。沿用原生 WXML/WXSS、TypeScript、既有 API 与恢复机制。

## 布局与功能对应

| 页面 | 新呈现与原能力位置 |
| --- | --- |
| 首页 | 「家」字标、提醒横幅、家庭/日期筛选、统一边框的分组清单；只读事项灰底与眼睛图标；完成/撤销、批量与待确认写入保留。无家庭时引导创建/加入。 |
| 快速新增弹层 | 标题、日期、家庭、更多安排、保存/连续新增。家人、时刻、重复、备注和权限通过「更多安排」进入完整编辑，沿用草稿交接。 |
| 事项详情 | 家庭与执行对象、标题、日期和状态卡、安排信息、备注、记录与周期操作；编辑/共享/删除/本人提醒位于事项设置。 |
| 完整编辑 | 内容 → 家庭/执行对象 → 重复分段与时刻 → 后续三次预览 → 按家人设置查看/代记/提醒。保留必要可见人、自行关闭提醒、冲突和重试限制。 |
| 家庭 | 资料卡、两行家庭卡（名称/箭头，人数/角色）、创建/加入、进度/回收入口；家庭详情的成员操作通过「管理」展开。保留邀请、虚拟人、转交和退出流程。 |
| 家人进度 | 紧凑「伴」字封面、家庭切换、日期/执行对象筛选、每人进度；共享口径与统计不变。 |
| 邀请 | 同一视觉体系的邀请创建、口令/分享、有效/撤销状态和接受表单；分享参数与接收流程不变。 |
| 回收站 | 家庭筛选、统一恢复卡片与空态；周期恢复说明保持与服务端一致。历史个人事项仍可从全部范围看到，未自动迁移数据。 |

## 样式与状态

- 主色 `#5059ad`、底色 `#f5f6fa`、正文 `#292b40`；沿用 tokens，统一 18px 卡片圆角/页面间距和 44px 以上操作区域。
- 首页 26px 标题、详情 28px 标题；按钮、表单、提醒、危险操作、抽屉、安全区和窄屏排布统一到 `miniprogram/styles/redesign.wxss`。
- loading/empty/error/ready、未知写结果、版本冲突、无家庭引导继续使用真实状态，不填充演示业务数据。
- 家庭摘要契约没有人数：页面通过既有 `family.get` 的真实成员与在用虚拟成员计算，不修改后端或增加 action。失败显示「人数暂未加载」，不伪造零人数；切页和上下文变化仍按 epoch 丢弃迟到结果。
- 未改变账号、家庭或事项权限，不自动迁移历史个人数据，不改变提醒为微信订阅通知。
