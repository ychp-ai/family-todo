# 页面流程与状态规范

视觉沿用 [主设计稿](../../design/index.html)，新增流程见 [完整流程设计](../../design/flows.html)。这两份浏览器稿共同表达首版，数据彼此独立、刷新重置。原生页面以功能命名，不按迭代编号命名，不新增业务 tabBar。

## 导航与页面交付

| 页面 / 原生路由建议 | 入口与退出 | 主要动作 / 接口 |
| --- | --- | --- |
| pages/home/index | 启动默认；详情返回保留日期、家庭、滚动位置 | task.list、reminder.list；新建、筛选、完成、多选共享 |
| pages/task-edit/index | 快速新增展开或详情编辑；有未保存草稿时返回确认保留/放弃 | task.previewSchedule、create/update/setAccess |
| pages/task-detail/index | 卡片或提醒；返回原列表 | task.get/history；单次 record/undo；系列 pause/resume/stop/delete |
| pages/family-progress/index | 首页家人入口 | progress.get；日期及家庭切换 |
| pages/families/index | 家人页管理入口；无家庭态仍可返回个人待办 | family.list/create/get/update；member.rename |
| pages/family-members/index | 家庭详情 | virtualMember.create/update/deactivate；邀请列表；移除/退出/转交 |
| pages/invitation/index | 分享邀请参数进入；已有成员直接进家庭 | preview → 用户确认 → accept；无效态重新联系邀请人 |
| pages/recycle/index | 首页更多或事项删除成功页 | recycleList → 恢复确认 → restore |

默认启动通过 identity.ensure 取得应用身份；加载失败保留重试，不把网络错误显示为“尚未加入家庭”。首次无家庭用个人首页，引导可选创建或加入，不强制邀请家人才能记事。

## 完整编辑

快速新增保留标题、日期、默认开启的“提醒我”；更多选项进入完整编辑。完整页顺序：标题/备注 → 所属家庭 → 执行对象 → 重复 → 起止日期/星期/时刻 → 谁可以看、代记、收到提醒。

- 个人默认自己，切到家庭才列出该家庭真实及有效虚拟成员；跨家庭切换时清空旧名单并提示，不能把爸妈家的成员带入小家。
- 已归属家庭的事项不提供迁移选项。将个人事项归属家庭时展示确认，保存失败保留草稿及原归属。
- 虚拟人用“无账号成员”标记，必要提示“由家庭拥有人管理”；普通浏览不堆叠内部归属字段。
- 选择真实家人为执行人时，保存前展示“爸爸将能查看并记录完成，无需接受”，必要查看锁定；该家人提醒仍需单独设置。更换执行人时展示“仅更改未来安排，历史保留原执行人”，涉及虚拟人时同时提示管理归属变化。
- 已完成一次性事项锁定日期、重复和执行对象，提供“另建事项”入口；已跳过时提示先撤销。已有历史的周期不提供转一次性选项，可停止后另建。历史详情和家人进度显示该次原执行人。
- 每周至少选一天；时刻每项可添加/删除，最多 6 个；不填时刻明确为“当天安排，不限定时刻”。日期空时不允许只留时刻。
- 新建今天的周期时，已过时刻在预览中跳过，显示后面三次有效安排；不能因为上午已过而拒绝今天晚上的安排。
- 修改系列展示“仅影响未来安排，过去记录保留”；暂停/停止/删除属于独立动作，不藏在重复下拉框。
- 权限表每个真实成员三列：可查看、可代记、接收提醒。必要可见人锁定并说明原因；虚拟人不出现在提醒接收列。新增可见只勾查看。
- 取消查看时，若有代记/提醒则先展示一并取消确认；取消确认保留原值，确认后同一次保存原子生效。
- 本人提醒默认开启，可关闭；其他人单独选。家人自行关闭后，管理者看到不可勾选的“已自行关闭，需本人开启”；取消后重新共享、重新加入及恢复不能解除此限制。本人仍可在自己的提醒设置中开启。保存遇到并发关闭时保留草稿并更新该项，不自动覆盖。无具体时刻时显示“已开启 · 待设置时刻”，不会补成午夜。

## 家庭、邀请与交接

创建家庭只填名称和自己的家庭称呼。成功进家庭详情。家庭列表明确每个家庭拥有人；不同家庭内角色独立。

拥有人生成邀请后看到 7 天有效期、分享及撤销入口，明确提示“邀请可转发，持有者可加入”；多人可用同一邀请，接收方无需额外审批。撤销只阻止后续加入，已加入成员需单独移除；原生实现调用用户主动触发的分享能力。接收方预览名称、邀请人，填写称呼，主动接受后加入。重复接受显示“你已加入”；过期/撤销显示统一不可用。浏览器只模拟邀请状态，不实际发出。

虚拟成员可添加、改名、停用。停用确认说明“历史记录保留，未结束事项继续由拥有人管理”；停用后从新建执行对象选项移除。

普通成员退出或被拥有人移除：预览承接人、普通事项数量、原仅自己可见事项数量及创建管理职责；明确个人和其他家庭不受影响。确认提交后该成员立即失权。预览过期则重新检查，禁止沿用旧承接人直接提交。

家庭拥有人退出入口先引导转交，承接者只能选有效真实成员；没有人可选时提供邀请入口。转交与退出分两次确认。转交说明虚拟人事项的实际归属随之变化，不改历史完成记录。交接界面不向尚无权的接收人泄露原私密事项标题。

## 每次记录、系列与回收

详情把“这一次”和“整个周期”分区。本次：完成、补记时间、跳过、撤销；整个周期：编辑后续、暂停、继续、停止后续、删除整个事项。仅可查看者隐藏写入口并显示说明。

- 完成显示执行人、实际完成时间和真实记录人；补记弹层限定有效时间，系统记录时间独立展示。
- 已完成/已跳过只能撤销后重记；未来周期不显示记录入口。跳过单列，不算完成，不进入应做分母。
- 暂停确认说明此前未完成仍保留；恢复先预览下一次，不补暂停期间。停止后不提供继续按钮，需要另建。
- 删除说明包含整个系列、历史与提醒暂时隐藏，可在回收入口恢复；提供回收入口链接。
- 回收列表只显示当前可管理项；恢复保留历史和有效权限，失效成员不会回来。周期恢复为暂停，再由用户继续；已停止系列恢复仅用于查看历史，不能继续。
- 空回收状态“暂时没有删除的事项”；恢复失败保留卡片并提供重试。

## 异步、冲突与可访问性

| 情况 | 明确反馈与恢复方式 |
| --- | --- |
| 页面 loading | 骨架及加载文案，避免可点击旧权限按钮 |
| 空列表 | 区分无安排、无家庭、无提醒；提供对应新增/返回入口 |
| 保存中 | 当前按钮禁用并显示“保存中”；关闭前确认草稿；不连发写请求 |
| 写超时/断网 | “暂未确认是否保存成功”，重试沿用 requestId；保留输入 |
| 版本冲突 | 告知家人已修改；保留本地草稿；查看最新差异后合并并使用新 requestId，不自动覆盖 |
| 部分聚合失败 | 显示受影响家庭及重试，隐藏完整总数，不把失败当成零 |
| 批量部分失败 | 每项结果与原因，成功项不再选择，只重试失败项 |
| 成员退出/权限失效 | 清除该家庭缓存、关闭编辑入口、返回有权页面；其他家庭筛选与数据保留 |
| 快速切换日期/家庭 | 请求带 context generation，旧响应到达不能覆盖新视图 |
| 卸载 / 返回前台 | 取消监听/定时器；返回后重新鉴权和刷新到时提醒 |

点击热区至少 44×44 CSS px；表单有可读标签，错误与字段相邻，状态不只依靠颜色。弹层进入聚焦标题或首个输入，关闭恢复触发点，键盘可退出；原生键盘弹起时保存按钮和错误提示不能被遮挡。动画尊重减少动态效果偏好。正式小程序还需验收安全区、微信胶囊、字体和真机输入行为。
