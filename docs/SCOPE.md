# 当前范围

已完成身份接入、个人及家庭一次性待办：新增、编辑、完成/补记/跳过与撤销、删除与回收站恢复、历史记录、本人提醒开关、到时提醒已读和收起。首页、详情、编辑、回收站、家庭管理、邀请六个原生页面使用真实 API，按 `design/` 实现。

家庭协作包括多家庭、真实及无账号成员、邀请预览/接受/撤销、退出/移除与拥有权转交、事项查看/代记/提醒权限、多家庭聚合与筛选。归属和创建管理职责通过历史成员承接关系解析；普通私密事项不会因家庭拥有人角色而公开。退出与转交先完整预览，再按当前家庭版本提交。详见 [家庭协作实现](technical/FAMILY.md)。

服务端使用单一 `api` 云函数，共36个 action。身份取自本次微信调用上下文；公开用户与实体使用应用 UUID。写入事务同时保存业务实体、容量/权限版本、历史和 requestId 回执。查询使用绑定用户、筛选及范围版本的签名游标，完整扫描后才发布统计；部分家庭失败不能显示完整总数。个人数据保持兼容，见 [个人待办实现](technical/PERSONAL.md)。
