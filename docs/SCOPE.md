# 当前范围

已完成身份接入、个人及家庭待办：新增、编辑、完成/补记/跳过与撤销、删除与回收站恢复、历史记录、本人提醒开关、到时提醒已读和收起。首页、详情、编辑、回收站、家庭管理、邀请、进度七个原生页面通过 services 使用 API，按 `design/` 实现。

首页默认隐藏已完成事项，可点击「显示已完成」查看记录。完成或撤销事项时，列表保留原内容并显示「刷新中…」半透明蒙层，直到列表读取结束；蒙层仅限列表区域，不覆盖底部「记一件事」按钮。完成提交和列表刷新期间均可打开新增表单并填写，保存按钮在当前操作结束后恢复，避免并发提交。失败或离开页面后撤下蒙层。当前列表在页面内缓存，30 秒内切回且账号、查看条件及业务写入版本未变化时直接复用；过期后保留画面刷新，跨天重新读取。支持列表下拉刷新，切换筛选条件和业务写入后重新查询；仍保留前台 30 秒刷新以更新协作事项与提醒。下拉手势尚待开发者工具或真机验证。

底部采用「首页 / 家庭」原生 tabBar；家庭页顶部展示昵称与头像，点击进入资料编辑，使用微信 `chooseAvatar` 和 `input type="nickname"` 获取用户主动选择的资料。资料按云环境和应用用户 ID 保存于本机，头像复制到持久文件目录；未设置时使用会话昵称及首字占位。家庭页首次读取后按当前账号复用页面内资料，来回切换不重复读取存储或检查头像文件；保存后立即更新，切换账号时重新读取。当前不跨设备同步，不修改服务端身份或家庭称呼。下方是家庭列表、创建/加入、家人进度与回收站。加入成功后通过 tab 切换打开对应家庭，读取时重新校验成员权限。

家庭协作包括多家庭、真实及无账号成员、邀请预览/接受/撤销、退出/移除与拥有权转交、事项查看/代记/提醒权限、多家庭聚合与筛选。归属和创建管理职责通过历史成员承接关系解析；普通私密事项不会因家庭拥有人角色而公开。退出与转交先完整预览，再按当前家庭版本提交。详见 [家庭协作实现](technical/FAMILY.md)。

周期支持每日、每周、起止日期及每天最多6个时刻，提供服务端预览、暂停、继续、停止和历史次数查询。已到时次数保留原日程和执行对象，未来次数不能提前记录；暂停及删除期间不补次数。周期从回收站恢复为暂停，停止过的周期不能重新继续。无具体时刻的事项不产生午夜提醒。旧一次性数据和请求回执保持兼容，详见 [日程实现](technical/SCHEDULING.md)。

家人进度按家庭、日期及执行对象汇总当前可见次数，完整扫描之前显示加载状态；跳过不计入完成分母。首页多选最多20个不同事项，按家庭追加可见人，个人事项需明确选择目标家庭；不自动追加代记或提醒权限。批量逐项提交，未完成使用原请求和全部原参数续办，全部终态后以新请求仅重试失败项。批量新增事项不在此范围。

服务端使用单一 `api` 云函数，共43个 action。身份取自本次微信调用上下文；公开用户与实体使用应用 UUID。写入事务同时保存业务实体、容量/权限版本、历史和 requestId 回执。查询游标绑定用户、筛选及范围版本，完整扫描后才发布统计；部分家庭失败不能显示完整总数。个人数据兼容基线见 [个人待办实现](technical/PERSONAL.md)。

现有云环境包含19个服务端专用集合，其中周期新增4个集合，API 已于2026-09-14更新。真实单账号的周期、进度和两项批量流程通过，暂停/停止、次数记录与回执重放均有读回证据，详见 [发布记录](technical/CLOUD_DEPLOYMENT.md)。开发者工具已补验每日/每周编辑预览及进度空态；有数据的原生进度、详情记录和批量确认仍待验收。接口验证与原生界面分开记录，不以 Page 模拟测试替代开发者工具或真机操作。

尚未实现订阅消息、后台定时提醒及云存储。双真实账号协作/隔离、iOS/Android 真机、微信分享及弱网交接仍需实测。目标容量与延迟测试数据见 [开发交付](business/DELIVERY.md)，小规模真实流程不代表性能目标已达成。进度最终执行人数组受单次运行/响应容量约束，极端数据返回可重试错误，可缩小执行对象范围；不显示局部最终统计。

未决业务写按经服务端确认的账号和环境保存原 requestId、原参数和版本，重启后可从首页主动重试确认，不自动提交。邀请接受包含口令，仅支持当前进程内重试，重启后重新预览确认。编辑器和快速新增保存未完成输入，返回和再次进入时可保留/放弃或恢复；恢复重新检查权限与版本，成功后清理关联草稿，详见 [异常恢复](technical/RECOVERY.md)。开发者工具验证不代表已上传微信体验版或已发布小程序。

首版完整规则见 [需求](REQUIREMENTS.md)。未经当前会话授权，不提交、推送、合并或发布；本次用户已授权 API 更新后自动部署到现有云环境。

家庭成员删除入口：家庭拥有人可删除其他真实成员，提交前展示默认交接影响；无账号成员的「删除成员」采用停用处理，删除后从家庭成员列表隐藏且不能用于新事项，历史身份、记录及未结束事项保留，由家庭拥有人继续管理。当前拥有人须先转交才能退出。

## 微信分享邀请

家庭拥有人在邀请页生成邀请后，点击「分享给微信好友」选择接收人。分享卡片打开带口令的邀请页，完成身份初始化后自动预览家庭信息；接收人填写家庭称呼，点击「接受邀请并加入」，成功后可查看家庭。有效的接收页再次转发仍保留邀请口令。分享进入且预览成功时隐藏手动口令输入，手动加入及邀请不可用时保留口令入口。沿用现有卡片、按钮与样式。

邀请仍有效 7 天、可转发供多人主动加入；过期或撤销由服务端拒绝，不因打开页面自动加入。使用微信原生 `open-type="share"` 和页面分享回调，参见[腾讯云带参分享说明](https://docs.cloudbase.net/recipes/add-share-with-params-miniprogram)。本地页面模拟覆盖分享参数、接收预览、主动加入和失效邀请；双微信账号实际发送、接收与真机操作仍待验证，未上传或发布小程序。

### 新增待办的默认家庭

- 快速添加与完整编辑共用当前设备上次选择的家庭偏好，按可信账号和云环境隔离；选择「个人事项」也会记住。
- 未设置偏好时，快速添加沿用首页家庭筛选作为初始归属；完整编辑默认个人事项。从家庭入口明确指定归属、已有事项和恢复草稿优先使用原归属。
- 偏好使用家庭 ID 匹配，家庭列表排序变化不影响选择；上次家庭已不在可访问列表时，新建默认回到个人事项。偏好存储失败不阻止正常编辑。

### 待办时间预警

首页事项卡片及「已超时」tab，对待完成且已到具体计划时刻的事项显示「已到计划时间」，早于上海当前日期的事项显示「计划日期已过」。卡片保持白底和原有勾选圈，时间信息旁显示暖琥珀色浅底标签，搭配 12px 时钟图标与文字，不仅靠颜色区分；标签随元信息自然换行，不增加独立提示行或持续动画。今天未限定时刻、未安排、已完成及已跳过事项不显示预警；撤销记录后随列表刷新重新判断。时间取列表服务端快照，沿用前台 30 秒刷新，与本人提醒开关、已读或收起状态无关。

### 已超时 tab 与日期请求

日期栏为「今天 / 明天 / 未安排 / 已超时 / 日期选择」。以往日期的未完成事项仅在手动切换「已超时」后查询并展示，取消首页积压折叠入口和预加载；卡片额外显示原计划日期，空态为「没有超时未完成事项」。超时页只统计未完成数量，不显示完成进度或已完成切换。

切换 tab、指定日期或家庭筛选仅调用当前范围的 `task.list`（有分页时继续读取相关页），复用已读取的家庭选项，保留全局提醒。首次进入、下拉及前台定期刷新读取家庭、当前列表和提醒；完成/撤销后读取当前列表和提醒。连续日期切换不推迟原有前台刷新周期。快速切换隔离旧响应，失败显示重试，不伪装为空列表。本地完整检查 500 项测试通过，新增 tab 的真机显示与操作尚待验证。
