# 当前范围

当前目标是搭建可继续开发的小程序基础工程，业务功能暂不实现。

已包含原生小程序入口、占位首页、通用页面状态、样式变量、npm workspaces、严格类型、五层共享包、统一 API、健康检查、时钟与 UUID 适配、构建测试、CI、环境模板和 AGENTS.md。

未包含登录与身份绑定、家庭和成员、待办 CRUD、事项分配和完成、提醒规则、订阅消息、定时任务、内容安全回调、数据库集合、云存储或部署。

后续产品方向仍为家庭管理、待办事项管理、待办事项提醒。具体角色、数据模型、导航和提醒渠道在对应业务任务中确定。

验收：`npm ci` 后 `npm run check` 可执行，空云配置可预览首页，基础链路具备可运行测试。云部署和真机联调属于后续环境接入。
