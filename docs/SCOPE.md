# 当前范围

当前代码已搭建可继续开发的小程序基础工程，业务功能尚未实现。首版产品需求已确定，见 [首版业务需求](REQUIREMENTS.md)。

已包含原生小程序入口、占位首页、通用页面状态、样式变量、npm workspaces、严格类型、五层共享包、统一 API、健康检查、时钟与 UUID 适配、构建测试、CI、环境模板和 AGENTS.md。

未包含登录与身份绑定、家庭和成员、待办 CRUD、事项分配和完成、提醒规则、订阅消息、定时任务、内容安全回调、数据库集合或云存储。2026-09-11 已通过 CloudBase CLI 在配置环境创建单一 api 云函数，并验证健康检查、非法请求及未实现 action 的错误响应，见 [发布记录](technical/CLOUD_DEPLOYMENT.md)。业务接口仍仅完成设计。

后续开发范围包括多家庭及虚拟人管理、待办协作与可见性、周期事项、小程序内提醒和跨家庭聚合。业务归属、权限及交接规则以首版需求为准，数据模型、接口和具体导航已在 [业务开发设计](business/DELIVERY.md) 中细化；实现分层、事务、日程算法和客户端策略见 [首版技术方案](TECHNICAL_DESIGN.md)；仍未实现业务 action、集合或原生业务页面。

验收：`npm ci` 后 `npm run check` 可执行，空云配置可预览首页，基础链路具备可运行测试。健康入口云部署及 CLI 调用已通过；可信业务身份、多成员和真机联调仍属于后续环境接入。
