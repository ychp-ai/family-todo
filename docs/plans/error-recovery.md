# 异常恢复实施计划

依据：用户要求“实现异常恢复”，以及 [页面恢复规则](../business/INTERACTIONS.md)。已有进程内重试、冲突及权限清理逻辑保持兼容，补齐退出或重启后恢复。

## Global Constraints

- 保留当前工作区周期、进度、批量追加等已有改动；本轮不提交或推送。沿用当前功能分支。
- 原生 WXML/WXSS 和现有错误提示、确认弹窗交互，不调整无关设计；不新增 API、数据库、后台自动写队列或订阅提醒。
- 可信身份确认后才读取该账号的恢复数据；本地内容始终是 unknown，校验版本、结构、action 和 payload。缓存不代表服务端授权。
- 写超时、断网和无效响应保留完整原始 payload 与 requestId；明确成功或业务拒绝才释放。批量 complete=false 仍未结束；同一请求 single flight，迟到结果不能清除新请求。
- 邀请口令不得写日志或本地存储。恢复必须由用户主动确认，不在启动或网络恢复时自动提交。
- 逻辑补行为测试；完整交付执行 npm run check；区分 Page 模拟与真实开发者工具/真机验证。

### Task 1: 重启后的未决写恢复

实现服务层持久化单个未决写，以及首页恢复入口。范围：services/personal-api.ts、服务层恢复存储模块、身份接入、首页必要状态及对应测试。

- 以云环境和已验证应用用户 ID 隔离存储；生产 personalApi 在身份确认后绑定恢复上下文，不在构造/module import 时访问 wx。测试依赖可注入，现有无持久化实例可用。
- 发送写请求前先可靠落盘 original action/payload/requestId。读取或写入存储失败时阻止新的可持久化写并提供可理解重试信息，不能先发送再冒险丢失 requestId。已明确成功但清除失败仍不能换 ID 重发，采用可恢复的完成标记或保留原请求并显示恢复入口。
- 对恢复记录使用显式可写 action 白名单及 contracts guards，保留版本和 batch 原完整 payload。损坏缓存不得静默当作无请求并继续新写；显示可操作恢复错误，不扩大为任意 action 重放。
- invitation.accept 含口令，维持仅内存重试（重启后重新预览确认加入）；invitation.create 的返回口令不持久化。不要把任何 API 结果整体存入本地。切换身份时不能重放旧账号写，旧在途响应不能破坏新账号 pending/batch。
- 恢复不自动写；首页在 readySession 后准确更新 pendingCount，可点击现有重试确认；继续批量重建 payload 状态，通过服务端重新取结果。
- 提供后续草稿模块需要的明确写完成通知/标记接口，确保 task.create 成功但进程在页面回调前退出不会留下可再次提交的旧新建草稿。
- 覆盖：重建实例同 ID 同原 payload；unknown guard/corrupt/read/write/remove failure；并发；迟到；批量 incomplete；账号隔离；邀请口令不落盘；首页首次身份绑定后能看见未决；确定拒绝释放而未知保留。
- 自检并运行针对本任务的测试与类型检查，完整报告写到 task brief 对应 report；不修改本轮文档（由主代理维护），不提交、不派生代理。

### Task 2: 编辑输入与草稿恢复

依赖 Task 1 的身份绑定和写完成信号。实现编辑器和首页快速新增的输入保留、返回确认以及重启恢复，配套行为测试。

- 复用账号/环境隔离存储；只保存编辑输入和恢复定位所需 ID/版本，不保存完整服务端 DTO、成员姓名/名册、邀请口令或已鉴权权限缓存。保存未完整/无效输入（例如空标题、半填时刻）不能依赖 PersonalDraft 校验才能存。
- 有修改时及时保存输入，onHide/onUnload 兜底；存储失败明确提示输入尚未持久化，不能谎称已保留。不对每次输入弹 Toast。
- 返回时依确认需求提供保留/放弃；下次进入相同编辑目标提供恢复/放弃，不自动提交。首页快速新增能发现上次输入。保存确认成功后消除对应草稿；未知结果必须先确认原请求，不能恢复成另一个 task.create。页面卸载后完成同样清理。
- 恢复已有事项须先读取 task.get/家庭名册并检查编辑或共享能力；权限拒绝清除相关本地草稿和敏感页数据。版本变动进入查看最新/显式合并流程，不把新 version 配旧完整草稿自动覆盖；现有合并行为为保留标题备注并重新核对最新日程/执行对象/权限。
- 家庭/成员变动需重新读取有效选项并明确告知无法恢复的输入，不能把旧家庭恢复为个人提交，不能恢复过去的代记/提醒授权；本人关闭提醒优先。
- 保持当前预览 epoch、分享模式、只读已完成次数日程、批量以及编辑 seed 交接行为；seed 与持久化草稿不得重复创建。
- 覆盖真实行为：离开再进入/重建模块恢复；保留与放弃；成功与未知写；失权清理；版本冲突；存储失败；快速新增完整编辑交接；账号隔离。
- 自检并运行针对本任务的测试与类型检查，完整报告写到 task brief 对应 report；不修改本轮文档，不提交、不派生代理。
