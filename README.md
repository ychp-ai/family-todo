# 家庭待办提醒

面向家庭成员协作的微信小程序，用于管理家庭、安排待办事项和接收事项提醒。

## 核心模块

- **家庭管理**：创建和加入家庭，管理家庭成员。
- **待办事项管理**：创建、编辑、分配和完成家庭待办事项。
- **待办事项提醒**：根据待办事项的提醒时间通知相关家庭成员。

> 原始需求中的“代码事项提醒”暂按“待办事项提醒”理解，后续可调整。
